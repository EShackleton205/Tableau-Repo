# Tableau Retail & Sales Dashboard Project

## Overview
This project was completed as part of a **Data Technician Bootcamp** and focuses on transforming retail and sales data into actionable business insights using **Tableau**. The goal was to explore sales performance, identify trends, and communicate key findings through interactive and visually engaging dashboards.

## Key Skills Demonstrated
- Designing and building **interactive Tableau dashboards**
- Creating and applying **filters, slicers, and dashboard actions** for dynamic data exploration
- Developing **calculated fields** to derive meaningful business metrics
- Building a variety of visualizations, including:
  - Bar Charts
  - Line Charts
  - Pie Charts
  - Geographic Maps
  - KPI Visuals and Trend Analysis
- Data cleaning, preparation, and visualization
- Dashboard layout and user-focused design
- Data storytelling and insight communication

## Dashboard Features
- Interactive filtering by product category, region, date, and sales metrics
- Drill-down functionality to explore data at different levels of detail
- Sales trend analysis over time
- Regional sales performance displayed through map visualizations
- Product and category comparisons using bar and pie charts
- KPI tracking for revenue, sales volume, and business performance

## Data Storytelling
A key focus of this project was **data storytelling**. Rather than simply presenting data, the dashboard was designed to guide users through meaningful business insights, helping stakeholders:
- Identify high-performing products and regions
- Monitor sales trends and seasonal patterns
- Compare performance across categories
- Make data-driven decisions based on visual evidence

## Tools & Technologies
- **Tableau Public / Tableau Desktop**
- Data Visualization
- Calculated Fields
- Interactive Dashboards
- Retail & Sales Analytics

## Learning Outcomes
Through this project, I strengthened my ability to:
- Transform raw data into clear visual insights
- Create professional and interactive business dashboards
- Apply visualization best practices
- Communicate findings through effective data storytelling
- Support business decision-making using retail and sales data analytics

## Project Outcome
The completed dashboard provides an interactive view of retail and sales performance, enabling users to explore trends, compare metrics, and uncover insights through intuitive visualizations and filtering capabilities.
